พิพิธภัณฑ์ : กรุงเทพ


พิพิธภัณฑ์สถานแห่งชาติพระนคร
ที่ขาดไม่ได้เลยก็คือ พิพิธภัณฑ์สถานแห่งชาติพระนคร พิพิธภัณฑ์สถานแห่งแรกในประเทศไทย ซึ่งเคยเป็นพื้นที่ของ
พระราชวังบวรสถานมงคล นั่นเองค่ะ ด้านในจะแบ่งออกเป็น 3 โซนหลักๆ ให้ทุกคนได้เดินชมความงาม และย้อนรำลึกถึงประวัติศาสตร์แผ่นดินไทย


ที่อยู่ : 1 ถนนพระนคร เขตพระนคร กรุงเทพมหานคร
พิกัด : https://goo.gl/maps/fEWQbTSoCyhrkBDVA\
เปิดให้เข้าชม : 09.00- 6.00 น. (เปิดวันพุธ-วันอาทิตย์)
โทร : 0-2222-3569
เว็ปไซต์ : https://www.facebook.com/nationalmuseumbangkok





ท้องฟ้าจำลอง กรุงเทพฯ
เอาใจคนชอบวิทยาศาสตร์ต่อด้วย ท้องฟ้าจำลอง ! เป็นสถานที่ในวัยเด็กที่ใครๆ ก็ต้องเคยไปกัน ไม่ว่าจะไปกับครอบครัวหรือไปกับโรงเรียนก็ตาม แต่ถึงจะโตแล้วก็ยังไปได้อยู่นะ เพราะที่นี่ได้รวบรวมข้อมูลความรู้เกี่ยวกับดาราศาสตร์ไว้แน่นเอี้ยด ให้ทุกคนได้ไปศึกษาเรื่องราวของดวงดาวต่างๆ ในจักรวาล แถมยังเป็นสถานที่เดทแสนโรแมนติกได้ด้วยนะ


ที่อยู่ : เลขที่ 928 ถนนสุขุมวิท แขวงพระโขนง เขตคลองเตย กรุงเทพมหานคร
พิกัด : https://goo.gl/maps/jwNREsYPRfZGmDTE7
เปิดให้เข้าชม : เวลา 09.00-16.30 น. หยุดทำการวันจันทร์และวันหยุดนักขัตฤกษ์
โทร : 0-2391-0544
เว็ปไซต์ : https://www.facebook.com/nationalmuseumbangkok





พิพิธภัณฑสถานธรรมชาติวิทยา แห่งจุฬาลงกรณ์มหาวิทยาลัย
เอาใจคนรักเรื่องราวของวิทยาศาสตร์ ประเภทชีววิทยากันบ้างกับ พิพิธภัณฑสถานธรรมชาติวิทยา แห่งจุฬาลงกรณ์มหาวิทยาลัย
ถ้าหากทุกคนได้เข้ามาสัมผัสที่แห่งนี้ จะได้เห็นโครงสร้างกระดูกของสัตว์หายากกันอย่างจุใจแน่นอน
นอกจากนี้ทุกคนยังจะได้เรียนรู้กับทรัพยากรธรรมชาติอื่นๆ กันอีกเพียบ เอาเป็นว่าคนรักสัตว์ และเรื่องราวของชีววิทยาไม่ควรพลาดเด็ดขาดเลย


ที่อยู่ :ตึกชีววิทยา 1 ชั้น 2 คณะวิทยาศาสตร์ จุฬาลงกรณ์มหาวิทยาลัย ถนนพญาไท แขวงวังใหม่ เขปทุมวัน กรุงเทพมหานคร
พิกัด : https://goo.gl/maps/S1ogcXHRUDN4i9Hx9
เปิดให้เข้าชม : 10.00-15.30 น.
โทร : -
